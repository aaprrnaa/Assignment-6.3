CSS Overflow Demonstration

Explore how CSS handles content that exceeds a container.

1. Overflow: Visible

This is a demonstration of visible overflow. When the content exceeds the fixed height of this container, it continues to display outside the box. The extra text is not clipped and may overlap other content below.

Additional text makes the overflow easier to see. This paragraph continues beyond the container.

2. Overflow: Hidden

This is a demonstration of hidden overflow. Content that extends beyond the fixed height of the container is clipped and cannot be seen.

This extra paragraph is hidden below the visible area of the box.

3. Overflow: Auto

This is a demonstration of automatic overflow. When content exceeds the container, a scrollbar appears as needed so users can access the rest.

Here is more text to make the content overflow. Scroll inside this box to read the remaining text.

The auto property avoids showing unnecessary scrollbars when all content fits.

4. Overflow: Scroll

This is a demonstration of scroll overflow. A scrolling mechanism is provided even when the content does not need to overflow.

Additional text makes it possible to scroll through the content inside this fixed-height box.

Keep scrolling to view all the text.
